# Micro-MWP — Wrap Simulator

Repository dedicata al catalogo e agli asset di Wrap Simulator, ripresi dall'handoff esistente.

Il catalogo raccolto comprende **170 originali verificati** e **55 PNG trasparenti nativi**, suddivisi in **14 ZIP autonomi**. Ogni modello include i metadati della fonte.

Tutti i 170 asset sono `NEEDS_MASK_REVIEW`: le maschere di wrapping e di esclusione sono ancora da completare. Nessun asset è `READY`.

Per scaricare tutti i pacchetti dalla pagina della repository, selezionare **Code → Download ZIP**. Estrarre l'archivio della repository e aprire `wrapsimulator_catalog/downloads`.

Per scaricare singoli pacchetti, consultare [l'elenco e le istruzioni](wrapsimulator_catalog/downloads/LEGGIMI_DOWNLOAD.md), aprire lo ZIP desiderato e usare il comando GitHub per scaricare il file raw.

Estrarre poi i pacchetti nella stessa cartella. Le parti sono ZIP indipendenti e non devono essere concatenate. [L'indice](wrapsimulator_catalog/downloads/INDICE_DOWNLOAD.csv) riporta i checksum SHA-256; [la verifica](wrapsimulator_catalog/downloads/VERIFICA_DOWNLOAD.json) documenta i controlli locali.
