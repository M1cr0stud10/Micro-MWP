# Micro-MWP — Wrap Simulator

Repository dedicata al catalogo e agli asset di Wrap Simulator, ripresi dall'handoff esistente.

Il catalogo raccolto comprende **170 originali verificati** e **55 PNG trasparenti nativi**, suddivisi in **14 ZIP autonomi**. Ogni modello include i metadati della fonte.

Tutti i 170 asset sono `NEEDS_MASK_REVIEW`: le maschere di wrapping e di esclusione sono ancora da completare. Nessun asset è `READY`.

I pacchetti possono essere estratti nella stessa cartella. Le parti sono ZIP indipendenti e non devono essere concatenate.
